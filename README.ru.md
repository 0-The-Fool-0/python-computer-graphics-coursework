# Программирование компьютерной графики на Python

[English version](README.md)

Учебные демонстрации растеризации, отсечения отрезков и преобразований трёхмерной модели. Алгоритмы вынесены в каталог `processing/`, а интерфейсы запускаются отдельными приложениями Streamlit.

## Разделы и точки входа

| Файл | Назначение |
|---|---|
| `app_raster.py` | Демонстрация и сравнение алгоритмов растеризации отрезков. |
| `app_clipping.py` | Отсечение отрезков прямоугольной областью, включая алгоритм Лианга—Барски. |
| `app_3d.py` | Работа с каркасной 3D-моделью и геометрическими преобразованиями. |
| `processing/raster.py` | Реализации растеризации. |
| `processing/clipping.py` | Геометрия отсечения. |
| `processing/transform3d.py` | Геометрия модели и трёхмерные преобразования. |

## Установка

```bash
python -m pip install -r requirements.txt
```

## Запуск приложений

Запускайте по одному приложению из корня репозитория:

```bash
streamlit run app_raster.py
streamlit run app_clipping.py
streamlit run app_3d.py
```

Команды основаны на структуре проекта; запуск приложений и тестов в этой среде не выполнялся.

## Ограничения

Это учебная коллекция алгоритмов, а не готовый графический движок. Нужно дополнительно проверить граничные случаи, точность реализаций и инструкции запуска.
